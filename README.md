**NoFishInThisPond** é uma extensão para o navegador Google Chrome focada em **proteger você contra sites suspeitos e tentativas de phishing**.

## 🚀 Sobre o projeto

A internet está cheia de ameaças disfarçadas em links aparentemente inofensivos. **NoFishInThisPond** atua como um guardião discreto, alertando o usuário sempre que ele acessa um domínio potencialmente perigoso.

## 🟢 Lançamento

A extensão foi lançada oficialmente na **Mozilla Add‑ons (Firefox)**. Você pode instalá‑la diretamente pela loja do Firefox:\
[https://addons.mozilla.org/pt-BR/firefox/addon/nofishinthispond/](https://addons.mozilla.org/pt-BR/firefox/addon/nofishinthispond/) 

### *se possivel deixe uma review seria mto interessante para mim*



### ⚙️ Funcionalidades principais:

- 🔎 Monitoramento ativo de URLs suspeitas.
- 🚨 Alerta visual ao detectar domínios perigosos.
- 📜 Lista de domínios atualizável.
- 💡 Leve, simples e discreta.





## 📦 Instalação (Para outros Navegadores) 

1. Clone este repositório:
   ```bash
   git clone https://github.com/SamuelV1/NoFishInThisPond.git
   ```

2. No Chrome/Brave/Opera:
   - Acesse `chrome://extensions/`
   - Ative o **Modo do desenvolvedor**
   - Clique em **"Carregar sem compactação"**
   - Selecione a pasta do projeto clonado
